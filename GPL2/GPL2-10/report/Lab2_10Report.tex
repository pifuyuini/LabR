	% 原理概述
	\subsection{原理概述（Principle）}
	
	这部分内容主要参考了文献[1]。
	
	塞曼效应是指在外部磁场的影响下，原子或分子的光谱线发生分裂或偏移的现象。这个效应是由荷兰物理学家皮特·塞曼（Pieter Zeeman）于1896年首次观察到的，他发现在磁场作用下，钠的黄色光谱线分裂为几条组分。塞曼效应的发现对原子物理学和量子力学的发展起到了重要的推动作用，塞曼因此与亨德里克·洛伦兹共同获得了1902年的诺贝尔物理学奖。
	
	\begin{figure}[htbp]
		\centering
		\includegraphics[width=0.4\textwidth]{Lab2_10GraP1.png}
		\caption{The spectral lines of mercury vapor lamp at wavelength 546.1 nm, showing anomalous Zeeman effect. (A) Without magnetic field. (B) With magnetic field, spectral lines split as transverse Zeeman effect. (C) With magnetic field, split as longitudinal Zeeman effect. The spectral lines were obtained using a Fabry–Pérot interferometer.（参考文献[1]）}
		\label{fig:figP1}
	\end{figure}
	
	塞曼效应可以分为两类：正常塞曼效应（在这种情况下，光谱线均匀地分裂成三条组分（一个π成分和两个σ成分），每条线的偏移与原始线相同。这种分裂可以通过基于洛伦兹电子理论的经典理论来解释）和反常塞曼效应（大多数情况下，光谱线的分裂比正常塞曼效应更复杂，可以分裂成多条线，分裂模式取决于涉及的电子态的特定量子数。反常塞曼效应的解释需要用到量子力学和电子自旋的概念）。
	
	塞曼效应的物理原理涉及到原子中电子的磁矩在外部磁场中的相互作用。电子的总磁矩是其轨道磁矩和自旋磁矩的矢量和。在外磁场中，这个磁矩与磁场的相互作用会导致原子能级的分裂，进而导致发射或吸收的光谱线相对于无磁场情况下发生移动或分裂。
	
	\begin{figure}[htbp]
		\centering
		\includegraphics[width=0.7\textwidth]{Lab2_10GraP2.png}
		\caption{Zeeman splitting of the 5s level of 87Rb, including fine structure and hyperfine structure splitting. Here $F = J + I$, where I is the nuclear spin (for 87Rb, $I = 3/2$).（参考文献[1]）}
		\label{fig:figP2}
	\end{figure}
	
	在量子力学框架下，塞曼效应涉及到角动量的量子化和磁量子数的概念。外磁场导致的能级分裂与总角动量量子数 \(J\)、轨道角动量量子数 \(L\) 和自旋量子数 \(S\) 相关。能级的偏移量与磁场强度和朗德 \(g\) 因子成正比，其中朗德因子是一个与电子态的角动量相关的因子，用于描述自旋和轨道对磁矩贡献的相对大小。
	
	塞曼效应在天体物理学、核磁共振（NMR）、电子自旋共振（ESR）等领域有广泛应用。在天体物理学中，通过观测恒星光谱的塞曼分裂，科学家可以推断恒星表面的磁场强度。此外，塞曼效应也是现代精密光谱测量技术的基础之一。
	
	\subsubsection{电子的磁矩}
	
	电子的轨道磁矩源自于电子绕原子核的运动，类似于经典电磁学中通过载流线圈产生的磁场。电子围绕核的运动产生电流，进而产生磁矩。轨道磁矩（\(\mu_l\)）的计算基于下述关系：
	\[
	\mu_l = -\frac{e}{2m_e} \vec{L}
	\]
	其中，\(e\) 是电子的电荷，\(m_e\) 是电子的质量，\(\vec{L}\) 是电子的轨道角动量。轨道角动量的大小是量子化的，依赖于主量子数 \(n\) 和角量子数 \(l\)，其 \(z\) 分量的可能取值为 \(m_l\hbar\)，其中 \(m_l\) 是磁量子数。因此，电子的轨道磁矩的 \(z\) 分量为：
	\[
	\mu_{l,z} = -m_l\mu_B
	\]
	这里的 \(\mu_B\) 是玻尔磁子，一个重要的物理常数，表示电子轨道角动量的最小磁矩单位。
	
	电子的自旋是其固有的量子属性，不同于经典的轨道运动。电子的自旋磁矩（\(\mu_s\)）与其自旋角动量（\(\vec{S}\)）相关，计算公式为：
	\[
	\mu_s = -g_s\frac{e}{2m_e}\vec{S}
	\]
	其中 \(g_s\) 是电子自旋的朗德 \(g\) 因子，理论值约为 2。自旋角动量的量子化表示其大小为 \(\sqrt{s(s+1)}\hbar\)，其中 \(s = \frac{1}{2}\)。自旋角动量的 \(z\) 分量可以取 \(\pm\frac{1}{2}\hbar\)，因此自旋磁矩的 \(z\) 分量为：
	\[
	\mu_{s,z} = -g_s m_s \mu_B
	\]
	其中 \(m_s = \pm\frac{1}{2}\)。
	
	电子的总磁矩（\(\vec{\mu}\)）是轨道磁矩和自旋磁矩的矢量和：
	\[
	\vec{\mu} = \vec{\mu}_l + \vec{\mu}_s
	\]
	在外部均匀磁场 \(\vec{B}\) 中，磁矩 \(\vec{\mu}\) 会经历力矩作用，并使系统具有势能 \(U\)，计算为：
	\[
	U = -\vec{\mu} \cdot \vec{B}
	\]
	这表明电子的磁矩倾向于与外磁场对齐以降低系统的势能。根据量子力学，总磁矩的 \(z\) 分量将决定能级分裂的具体情况，这是研究塞曼效应中至关重要的一步。
	
	\subsubsection{角动量的耦合}
	
	当两个角动量耦合时，如电子的轨道角动量 \(\vec{L}\) 和自旋角动量 \(\vec{S}\)，它们的总角动量 \(\vec{J}\) 由下式给出：
	\[
	\vec{J} = \vec{L} + \vec{S}
	\]
	这种耦合主要体现在量子力学中，其中角动量的每个组分都具有特定的量子数和相应的量子态。总角动量的大小和方向由以下量子数描述：
	\(J\) 是总角动量的量子数，它的可能取值范围为 \(|L - S|\) 到 \(L + S\)，包括所有整数步长。
	\(M_J\) 是总角动量 \(J\) 在选定方向（通常为磁场方向，即 \(z\) 轴）的投影的磁量子数，其取值从 \(-J\) 到 \(+J\)。
	
	在原子物理学中，除了氢原子（只有一个电子）之外，其他所有拥有两个或更多电子的原子都被称为多电子原子。多电子原子的电子排布和能级结构比氢原子复杂得多，因为它们不仅受到核的吸引，电子之间的相互作用（电子-电子排斥）也显著影响其能态。
	
	电子组态描述了多电子原子中电子的分布状态，通常表达为电子所处的量子态（如能级、角动量等）。每个电子的状态可以由四个量子数描述：
	主量子数 \(n\)：决定电子的能级和电子云的大小。
	角量子数 \(l\)：与电子的轨道角动量有关，\(l\) 的取值从 0 到 \(n-1\)。
	磁量子数 \(m_l\)：轨道角动量在特定方向（如 \(z\) 轴）的投影，其值从 \(-l\) 到 \(l\)。
	自旋量子数 \(m_s\)：电子自旋的 \(z\) 轴投影，取值 \(\pm 1/2\)。
	
	在实际书写中，电子组态是通过填充原子轨道来描述的。例如，氧原子（\(O\)）的基态电子组态可以写为 \(1s^2 2s^2 2p^4\)，这意味着第一个能级的 \(s\) 轨道有两个电子，第二个能级的 \(s\) 轨道有两个电子，\(p\) 轨道有四个电子。
	
	在多电子原子中，每个电子的轨道和自旋角动量会耦合，影响原子的能级和光谱。自旋-轨道耦合导致能级分裂，其中每个分裂能级的大小也由朗德 \(g\) 因子决定，这是一个量化轨道和自旋对磁场响应的重要参数。朗德因子的计算公式为：
	\[
	g_J = 1 + \frac{J(J + 1) + S(S + 1) - L(L + 1)}{2J(J + 1)}
	\]
	其中，\(L\) 是总轨道角动量量子数，\(S\) 是总自旋角动量量子数，\(J\) 是总角动量量子数。
	
	在多电子原子中，每个电子的轨道角动量和自旋角动量首先相互耦合形成自旋-轨道耦合，这对于描述电子的能级和光谱性质非常重要。自旋-轨道耦合主要发生在原子内部，由于电子绕原子核的运动产生的磁场对电子自旋的影响而引起。这种耦合的能量可通过以下公式近似计算：
	\[
	H_{SO} = \xi(r) \vec{L} \cdot \vec{S}
	\]
	其中，\(\xi(r)\) 是自旋-轨道耦合参数，它依赖于电子到原子核的距离 \(r\)。
	
	由于自旋-轨道耦合，特定能级会根据 \(L\) 和 \(S\) 的不同组合分裂为多个子能级，每个子能级对应一个特定的 \(J\) 值。自旋-轨道耦合影响原子从一能级到另一能级的跃迁，这些跃迁受到所谓的选择定则约束，这些规则指定了允许的电子跃迁的 \(\Delta L\)、\(\Delta S\) 和 \(\Delta J\) 的值。
	
	\subsubsection{基本理论}
	
	原子在磁场中的总哈密顿量为
	
	$$
	H = H_0 + V_M,
	$$
	
	其中，$H_0$ 是原子的未扰动哈密顿量，而 $V_M$ 是磁场引起的微扰：
	
	$$
	V_M = - \vec{\mu} \cdot \vec{B},
	$$
	
	其中 $\vec{\mu}$ 是原子的磁矩。磁矩包括电子和核的部分；然而，后者小得多，可以忽略不计。因此，
	
	$$
	\vec{\mu} \approx -\mu_B g \frac{\vec{J}}{\hbar},
	$$
	
	其中 $\mu_B$ 是玻尔磁子，$\vec{J}$ 是总电子角动量，$g$ 是朗德g因子。一种更精确的方法是考虑到电子磁矩算符是轨道角动量 $\vec{L}$ 和自旋角动量 $\vec{S}$ 的贡献之和，每个都乘以适当的回旋磁比：
	
	$$
	\vec{\mu} = -\mu_B \left( g_l \frac{\vec{L}}{\hbar} + g_s \frac{\vec{S}}{\hbar} \right),
	$$
	
	其中 $g_l = 1$ 和 $g_s \approx 2.0023193$（后者称为异常回旋磁比；其值偏离2是由于量子电动力学效应）。在LS耦合的情况下，可以对原子中所有电子求和：
	
	$$
	g \vec{J} = \left\langle \sum_i \left( g_l \vec{l}_i + g_s \vec{s}_i \right) \right\rangle = \left\langle g_l \vec{L} + g_s \vec{S} \right\rangle,
	$$
	
	其中 $\vec{L}$ 和 $\vec{S}$ 分别是原子的总轨道角动量和自旋角动量，求平均值是对具有给定总角动量的状态进行的。
	
	如果相互作用项 $V_M$ 很小（小于精细结构），可以将其视为微扰；这就是正常的塞曼效应。在下面描述的帕申–巴克效应中，$V_M$ 显著超过了LS耦合（但仍小于 $H_0$）。在超强磁场中，磁场相互作用可能超过 $H_0$，在这种情况下，原子将不再以其正常意义存在，而是讨论朗道能级。还有一些比这些极限情况更复杂的中间情况。
	
	\subsubsection{弱场的塞曼效应}
	
	如果自旋–轨道相互作用比外部磁场的作用更强，则 $\vec{L}$ 和 $\vec{S}$ 分别不再守恒，只有总角动量 $\vec{J} = \vec{L} + \vec{S}$ 是守恒的。自旋和轨道角动量矢量可以看作绕着（固定的）总角动量矢量 $\vec{J}$ 进动。此时的（时间上）“平均”自旋矢量是自旋在 $\vec{J}$ 方向上的投影：
	
	$$
	\vec{S}_{\text{avg}} = \frac{(\vec{S} \cdot \vec{J})}{J^2} \vec{J}
	$$
	
	对于（时间上）“平均”的轨道矢量：
	
	$$
	\vec{L}_{\text{avg}} = \frac{(\vec{L} \cdot \vec{J})}{J^2} \vec{J}
	$$
	
	因此，
	
	$$
	\langle V_M \rangle = \mu_B \frac{\vec{J}}{\hbar} \left( g_L \frac{\vec{L} \cdot \vec{J}}{J^2} + g_S \frac{\vec{S} \cdot \vec{J}}{J^2} \right) \cdot \vec{B}
	$$
	
	使用 $\vec{L} = \vec{J} - \vec{S}$ 并对两边平方，我们得到
	
	$$
	\vec{S} \cdot \vec{J} = \frac{1}{2} \left( J^2 + S^2 - L^2 \right) = \frac{\hbar^2}{2} \left[ j(j + 1) - l(l + 1) + s(s + 1) \right]
	$$
	
	同理，使用 $\vec{S} = \vec{J} - \vec{L}$ 并对两边平方，我们得到
	
	$$
	\vec{L} \cdot \vec{J} = \frac{1}{2} \left( J^2 - S^2 + L^2 \right) = \frac{\hbar^2}{2} \left[ j(j + 1) + l(l + 1) - s(s + 1) \right]
	$$
	
	综合以上所有并取 $J_z = \hbar m_j$，我们得到原子在外加磁场中的磁势能
	
	$$
	V_M = \mu_B B m_j \left[ \frac{g_L \left( j(j + 1) + l(l + 1) - s(s + 1) \right) + g_S \left( j(j + 1) - l(l + 1) + s(s + 1) \right)}{2 j(j + 1)} \right]
	$$
	
	$$
	= \mu_B B m_j \left[ 1 + \frac{(g_S - 1) \left( j(j + 1) - l(l + 1) + s(s + 1) \right)}{2 j(j + 1)} \right]
	$$
	
	$$
	= \mu_B B m_j g_j
	$$
	
	其中方括号内的量是原子的朗德g因子 $g_J$（$g_L = 1$ 和 $g_S \approx 2$），$m_j$ 是总角动量的z分量。对于单个电子在填充壳层之上，$s = 1/2$ 并且 $j = l \pm s$，朗德g因子可以简化为：
	
	$$
	g_j = 1 \pm \frac{g_S - 1}{2l + 1}
	$$
	
	将 $V_M$ 视为微扰，塞曼效应对能量的修正为
	
	$$
	E_Z^{(1)} = \langle n l j m_j | H_Z' | n l j m_j \rangle = \langle V_M \rangle \Psi = \mu_B g_J B_{\text{ext}} m_j
	$$
	
	示例：氢原子的莱曼-阿尔法跃迁
	
	在存在自旋–轨道相互作用的情况下，氢原子的莱曼-阿尔法跃迁涉及以下跃迁：
	
	$$
	2P_{1/2} \rightarrow 1S_{1/2} \quad \text{和} \quad 2P_{3/2} \rightarrow 1S_{1/2}

	在外部磁场存在的情况下，弱场塞曼效应将 $1S_{1/2}$ 和 $2P_{1/2}$ 能级分裂成2个态（$m_j = \pm 1/2$），将 $2P_{3/2}$ 能级分裂成4个态（$m_j = \pm 3/2, \pm 1/2$）。三个能级的朗德g因子分别为：

	$$

	$$

	\subsubsection{强场的塞曼效应}
	帕申–巴克效应是在强磁场存在下原子能级的分裂。当外部磁场足够强以破坏轨道（$\vec{L}$）和自旋（$\vec{S}$）角动量之间的耦合时，就会发生这种效应。这种效应是塞曼效应的强场极限。当 $s = 0$ 时，这两种效应是等价的。该效应以德国物理学家Friedrich Paschen和Ernst E. A. Back的名字命名。
	
	当磁场微扰显著超过自旋–轨道相互作用时，可以安全地假设 $[H_0, S] = 0$。这使得对于态 $|\psi\rangle$，$L_z$ 和 $S_z$ 的期望值可以很容易地求出。能量简单为
	
	$$
	E_z = \langle \psi | H_0 + B_z \mu_B \frac{1}{\hbar} (L_z + g_s S_z) | \psi \rangle = E_0 + B_z \mu_B (m_l + g_s m_s).
	$$
	
	上述公式可以理解为LS耦合被外部磁场完全破坏。然而，$m_l$ 和 $m_s$ 仍然是“良好”的量子数。结合电偶极跃迁的选择规则，即 $\Delta s = 0, \Delta m_s = 0, \Delta l = \pm 1, \Delta m_l = 0, \pm 1$，这允许完全忽略自旋自由度。结果，只有三条光谱线可见，对应于 $\Delta m_l = 0, \pm 1$ 的选择规则。分裂 $\Delta E = B \mu_B \Delta m_l$ 独立于未扰动的能量和考虑的能级的电子构型。
	
	更准确地说，如果 $s \neq 0$，则由于残余自旋–轨道耦合和相对论修正（这与所谓的“精细结构”同级别），这三个分量中的每一个实际上是一组若干跃迁。对于帕申–巴克极限下的氢原子，带有这些修正的一阶微扰理论给出了以下公式：
	
	$$
	E_z + f_s = E_z + \frac{m_e c^2 \alpha^4}{2n^3} \left\{ \frac{3}{4n} - \left[ l(l + 1) - m_l m_s \frac{l (l + 1/2) (l + 1)}{l (l + 1/2) (l + 1)} \right] \right\}.
	$$

	\subsubsection{实验仪器介绍}
	\begin{enumerate}
		\item 法布里—珀罗标准具
		
		F-P 标准具由平行放置的两块平面板组成的, 在两板相对的平面上镀薄银膜和其他有较高反射系数的薄膜, 若两平行的镀银平面的间隔不可以改变，则称该仪器为“法布里—珀罗干涉仪”。由于两镀膜面平行，若使用扩展光源，则产生等倾干涉条纹。具有相同入射角的光线在垂直于观察方向的平面上的轨迹是一组同心圆。若在光路上放置透镜，则在透镜焦平面上得到一组同心圆环图样。 在透射光束中，相邻光束的光程差为:
		\[
		\Delta = 2 n d cos \phi	
		\]
		
		产生亮条纹的条件为：
		\[
		2 n d cos \phi = K \lambda
		\]
		
		其中K为干涉条纹级数，$\lambda$为入射光波长。
		
		标准具的两个特征参量是自由光谱范围和分辨本领。
		
		\begin{itemize}
			\item 自由光谱范围：同一光源发出的具有微小波长差的单色光$\lambda_1$和$\lambda_2$，入射后将形成各自的圆环系列。对同一级的干涉条纹，波长大的干涉圆环直径小。对于某单色光来说，越靠中心处的干涉条纹的级数 K 越大。
			
			如果$\lambda_1$和$\lambda_2$的波数差逐渐增大，使得$\lambda_1$的第$m$级亮纹与$\lambda_2$的第$m - 1$级亮纹重合，则有
			\[
			2 n d \cos \theta = m \lambda _1 = (m - 1)\lambda_2	
			\]
			
			得出$\Delta \lambda = \lambda _2 - \lambda_1 = \frac{\lambda_2}{m}$
			
			由于大多数情况下，$\cos \theta \approx 1$，可得到$m = \approx \frac{2 n d}{\lambda_1}$，得
			\[
			\Delta \lambda = \frac{\lambda_1 \lambda_2}{2 n d} \approx \frac{\lambda^2}{2 n d}	
			\]
			
			它表明在 F-P 干涉仪中，当给定两平面间隔d后，入射光波长在$\lambda \pm \Delta \lambda$内不会发生干涉圆环重叠。
			
			\item 分辨本领：对于F-P标准具，它的分辨本领为$\frac{\Delta \lambda}{\lambda} = K N$，K为干涉级次,N为精细度, 它的物理意义是在相邻两个干涉级之间能分辨的最大条纹数。N依赖于平板内表面反射膜的反射率R:
			\[
			N = \frac{\pi \sqrt{R}}{1 -1R}	
			\]
			
			反射率R越高，精细度N就越高，仪器能分辨开的条纹数就越多。
			
		\end{itemize}
		
		\item 波数差与圆环直径之间的关系
		
		通过测量干涉环的直径就可以测量各分裂谱线的波长或波长差。
		
		如\cref{fig:graph1-9}所示，出射角为$\theta$的的圆环直径D与透镜焦距f间的关系为$\tan{\theta}=\frac{D}{2f}$，对于近中心的圆环$\theta$很小，可以认为$\theta\approx\sin{\theta}\approx\tan{\theta}$，于是有：
		\[
		cos\theta = 1 - 2 \sin^2\frac{\theta}{2} \approx 1 - \frac{\theta^2}{2} = 1 - \frac{D^2}{8f^2}	
		\]
		
		\begin{figure}[H]
			\centering
			\includegraphics[width=0.8\textwidth]{graph1-9.png}
			\caption{法布里一珀罗(F-P)标准具光路图(图中的透镜指的是望远镜里的透镜)}
			\label{fig:graph1-9}
		\end{figure}
		
		\[
		2 n d \cos \theta = 2 n d (1 - \frac{D^2}{8f^2}) = K \lambda	
		\]
		
		由上式可推出同一波长$\lambda$相邻两级$K$和$K - 1$级圆环直径的平方差为
		\[
		\Delta D^2 = D^2_{K-1} - D^2_{K} = \frac{4 f^2 \lambda}{n d}	
		\]
		
		设不同波长$\lambda$和$\lambda_{\alpha}$的第K级干涉圆环直径分别为$D_K$和$D_{\alpha}$
		\[
		\lambda - \lambda_\alpha = \frac{nd}{4 f^2 K}(D^2_\alpha - D^2_K) = (\frac{D^2_\alpha - D^2_K}{D^2_{K-1} - D^2_{K}})\frac{\lambda}{K}	
		\]
		
		得出波长差为：
		\[
		\Delta \lambda = \frac{\lambda^2}{2 n d}(\frac{D^2_\alpha - D^2_K}{D^2_{K-1} - D^2_{K}})
		\]
		
		波数差为：
		\[
		\Delta \tilde{\nu} = \frac{1}{2 n d}(\frac{D^2_\alpha - D^2_K}{D^2_{K-1} - D^2_{K}})
		\]
		
		\item 通过塞曼效应计算电子荷质比e/m
		
		本实验只研究反常塞曼效应的线偏振$\pi$的谱线。
		\[
		\frac{e}{m} = \frac{4\pi c}{n d B}(\frac{D^2_\alpha - D^2_K}{D^2_{K-1} - D^2_{K}})
		\]
		
		若已知$d$和$B$，从塞曼分裂中测量出各环的直径，就可以计算出荷质比。
	\end{enumerate}

	\subsection{实验前思考题（Questions）}
	
	% 思考题1
	\begin{question}
		光子是否具有角动量？试描述光子角动量方向与光的偏振方向之间的关系。
	\end{question}
	\begin{itemize}
		\item 光子的角动量
		\begin{itemize}
			\item 光子不仅携带能量和动量，还携带角动量。光子的角动量可以通过偏振光来体现，其中包括线偏振光和圆偏振光。
		\end{itemize}
		
		\item 线偏振光
		\begin{itemize}
			\item 对于线偏振光，电场矢量在某一固定方向上作周期性变化。例如，如果电场矢量在x方向上振荡，这就是线偏振光。
		\end{itemize}
		
		\item 圆偏振光
		\begin{itemize}
			\item 圆偏振光的电场矢量在某个平面上绕圆周旋转，使得合成电场矢量的大小保持恒定。根据旋转方向的不同，圆偏振光分为左旋圆偏振光和右旋圆偏振光：
			\begin{itemize}
				\item 左旋圆偏振光：从光的传播方向看，电场矢量逆时针旋转。
				\item 右旋圆偏振光：从光的传播方向看，电场矢量顺时针旋转。
			\end{itemize}
		\end{itemize}
		
		\item 光子角动量方向与光的偏振方向的关系
		\begin{itemize}
			\item 光子的角动量方向与光的偏振状态密切相关：
			\begin{itemize}
				\item 对于右旋圆偏振光，光子的角动量方向与光的传播方向相反。
				\item 对于左旋圆偏振光，光子的角动量方向与光的传播方向一致。
			\end{itemize}
		\end{itemize}
		
		\item 图示描述
		\begin{itemize}
			\item 在讲义中通过图10描述了光子角动量方向和电场矢量旋转方向的关系：
			\begin{itemize}
				\item 图10（a）显示了右旋圆偏振光的情况，此时光子的角动量方向与光的传播方向相反。
				\item 图10（b）显示了左旋圆偏振光的情况，此时光子的角动量方向与光的传播方向一致。
			\end{itemize}
		\end{itemize}
		
		\item 具体描述
		\begin{itemize}
			\item 光子角动量方向与光的偏振方向之间的关系如下：
			\begin{itemize}
				\item 线偏振光：电场矢量在一个固定方向上周期性振荡，光子的角动量方向与传播方向无关。
				\item 圆偏振光：电场矢量在平面内旋转，角动量方向与电场矢量旋转方向一致，决定了光子的偏振态。
			\end{itemize}
		\end{itemize}
	\end{itemize}
	
	
	% 思考题2
	\begin{question}
		用同一级条纹的内外圈分别计算电子的荷质比，结果一样吗？试简述原因。
	\end{question}
	\begin{itemize}
		\item 原理概述
		\begin{itemize}
			\item 在塞曼效应实验中，我们通过观察汞原子谱线在外磁场中的分裂现象来测量电子的荷质比。使用法布里-珀罗（F-P）标准具观察干涉条纹，通过测量相邻干涉条纹的直径差来计算波长差，并进一步计算电子的荷质比。
		\end{itemize}
		
		\item 计算方法
		\begin{itemize}
			\item 讲义中提到，通过测量干涉环的直径可以测量各分裂谱线的波长或波长差。公式如下：
			\[
			\Delta \lambda = \frac{\lambda^2}{2nd} \left( \frac{D_{a}^2 - D_{K}^2}{D_{K-1}^2 - D_{K}^2} \right)
			\]
			
			\item 由此波长差对应的波数差为：
			\[
			\Delta \tilde{\nu} = \frac{1}{2nd} \left( \frac{D_{a}^2 - D_{K}^2}{D_{K-1}^2 - D_{K}^2} \right)
			\]
			
			\item 结合公式：
			\[
			\Delta \tilde{\nu} = \frac{eB}{4\pi m c} (M_2 g_2 - M_1 g_1)
			\]
			
			\item 最终可得电子的荷质比为：
			\[
			\frac{e}{m} = \frac{4\pi c}{ndB} \left( \frac{D_{a}^2 - D_{K}^2}{D_{K-1}^2 - D_{K}^2} \right)
			\]
		\end{itemize}
		
		\item 不同条纹的结果差异
		\begin{itemize}
			\item 用同一级条纹的内外圈计算电子的荷质比，结果会有所不同。这主要是由于以下原因：
			\begin{enumerate}
				\item 条纹级数差异：
				\begin{itemize}
					\item 内圈和外圈对应的干涉条纹级数不同，导致干涉级次K不同。
					\item 计算中涉及的直径平方差 \((D_{a}^2 - D_{K}^2)\) 和 \((D_{K-1}^2 - D_{K}^2)\) 会有所不同。
					\item 由于这些差异，会影响最终计算结果。
				\end{itemize}
				
				\item 精度和分辨率：
				\begin{itemize}
					\item 外圈条纹的直径较大，相对误差较小，测量精度较高。
					\item 内圈条纹的直径较小，相对误差较大，测量精度较低。
					\item 因此，使用外圈条纹计算得到的结果通常比内圈条纹更精确。
				\end{itemize}
				
				\item 仪器因素：
				\begin{itemize}
					\item F-P标准具的分辨率和精细度可能会影响内外圈条纹的清晰度和测量精度。
					\item 仪器调整、光源稳定性等因素也会对测量结果产生影响。
				\end{itemize}
			\end{enumerate}
		\end{itemize}
		
		\item 总结
		\begin{itemize}

		\[ \vec{F} = -\nabla U \]

	\begin{question}
		请回答什么是“反常塞曼效应”和“正常塞曼效应”，两者之间的区别是什么。请思考什么是“帕邢－巴克效应”及其形成的原因。
	\end{question}
	\begin{enumerate}
		\item 正常塞曼效应与反常塞曼效应
		
		\textbf{正常塞曼效应}
		\begin{itemize}
			\item 正常塞曼效应（Normal Zeeman Effect）是指在弱外磁场中，原子或离子的能级在外磁场的作用下分裂成三条等间距的谱线。这种现象通常发生在单个电子轨道角动量较大的情况下。
			\item 具体特征：
			\begin{itemize}
				\item 特征谱线：分裂成三条等间距的谱线，即一条原来的中心线和两条对称分布在中心线两侧的偏振光谱线。
				\item 电子自旋：对于无自旋（\(S = 0\)）或自旋对消的情况（如单个电子的氢原子谱线）。
				\item 条件：通常在弱磁场下观察到。
			\end{itemize}
			\item 解释：能级分裂可以用经典理论解释，即每个能级的分裂是由于轨道磁矩在外磁场中的取向量子化所致。分裂能级间的间距与外磁场的强度成正比。
		\end{itemize}
		
		\textbf{反常塞曼效应}
		\begin{itemize}
			\item 反常塞曼效应（Anomalous Zeeman Effect）是指在弱外磁场中，原子或离子的能级在外磁场的作用下分裂成多条谱线（多于三条）。这种现象发生在电子自旋 \(S \neq 0\) 的情况下。
			\item 具体特征：
			\begin{itemize}
				\item 特征谱线：分裂成多于三条谱线，不等间距。
				\item 电子自旋：对于有自旋（\(S \neq 0\)）的情况，如多电子原子。
				\item 条件：通常在弱磁场下观察到。
			\end{itemize}
			\item 解释：分裂现象不能仅用经典理论解释，需要量子力学的自旋-轨道耦合理论来解释。分裂能级之间的间距和外磁场强度、朗德因子 \(g\) 有关。
		\end{itemize}
		
		\item 帕邢－巴克效应
		
		帕邢－巴克效应（Paschen-Back Effect）是指在强外磁场中，原子或离子的能级分裂情况不同于弱磁场下的正常或反常塞曼效应。
		\begin{itemize}
			\item 强磁场效应：外磁场强度很大，使得自旋-轨道耦合效应被外磁场的相互作用所压倒。
			\item 能级分裂：在强磁场下，自旋和轨道角动量分别绕外磁场方向进行拉莫尔进动，导致能级分裂的规律变化。
			\item 电子自旋：自旋和轨道角动量不再耦合成总角动量 \(J\)，而是分别与外磁场相互作用。
			\item 形成原因：在强磁场下，自旋-轨道耦合效应变得次要，电子的自旋和轨道角动量分别绕外磁场方向进行拉莫尔进动，导致能级分裂的形式与在弱磁场下的情况不同。
		\end{itemize}
		
		\item 总结
		
		\begin{itemize}
			\item 正常塞曼效应：在弱磁场下，\(S = 0\) 的情况下，能级分裂成三条等间距谱线。
			\item 反常塞曼效应：在弱磁场下，\(S \neq 0\) 的情况下，能级分裂成多条不等间距谱线。
			\item 帕邢－巴克效应：在强磁场下，自旋-轨道耦合效应被外外磁场相互作用压倒，能级分裂形式不同于弱磁场下的塞曼效应。
		\end{itemize}
	\end{enumerate}

		\item 自旋—轨道耦合
		
		\textbf{本质}
		\begin{itemize}
			\item 自旋—轨道耦合（Spin-Orbit Coupling）的本质是电子的轨道运动所产生的磁场与电子自旋磁矩之间的相互作用。具体来说，当电子在原子核周围运动时，它产生的轨道磁矩与其自身的自旋磁矩之间发生相互作用。这种相互作用导致电子的总角动量 \( \vec{J} \) 的形成，即轨道角动量 \( \vec{L} \) 和自旋角动量 \( \vec{S} \) 的耦合。
		\end{itemize}
		
		\textbf{具体特征}
		\begin{itemize}
			\item 自旋磁矩：电子的自旋 \( \vec{S} \) 产生自旋磁矩 \( \vec{\mu}_S \)。
			\item 轨道磁矩：电子的轨道运动产生轨道磁矩 \( \vec{\mu}_L \)。
			\item 相互作用：自旋磁矩 \( \vec{\mu}_S \) 与轨道磁矩 \( \vec{\mu}_L \) 相互作用，导致能级分裂。
		\end{itemize}
		
		\item L-S 耦合
		
		\textbf{本质}
		\begin{itemize}
			\item L-S 耦合（Russell-Saunders Coupling 或 LS Coupling）的本质是多电子原子中各电子的轨道角动量 \( \vec{L} \) 和自旋角动量 \( \vec{S} \) 的相互作用。具体来说，L-S 耦合是指在多电子原子中，所有电子的轨道角动量和自旋角动量分别进行矢量相加，形成总轨道角动量 \( \vec{L} \) 和总自旋角动量 \( \vec{S} \)，然后再将 \( \vec{L} \) 和 \( \vec{S} \) 耦合成总角动量 \( \vec{J} \)。
		\end{itemize}
		
		\textbf{具体特征}
		\begin{itemize}
			\item 单电子的轨道角动量：每个电子的轨道角动量 \( \vec{L_i} \)。
			\item 单电子的自旋角动量：每个电子的自旋角动量 \( \vec{S_i} \)。
			\item 总轨道角动量：所有电子的轨道角动量的矢量和 \( \vec{L} = \sum \vec{L_i} \)。
			\item 总自旋角动量：所有电子的自旋角动量的矢量和 \( \vec{S} = \sum \vec{S_i} \)。
			\item 总角动量：总轨道角动量 \( \vec{L} \) 和总自旋角动量 \( \vec{S} \) 再耦合成总角动量 \( \vec{J} = \vec{L} + \vec{S} \)。
		\end{itemize}
		
		\item 区别总结
		
		\begin{itemize}
			\item 自旋—轨道耦合：涉及单个电子的自旋磁矩和轨道磁矩的相互作用，导致能级分裂。它主要用于描述单电子或单电子类似原子的光谱精细结构。
			\item L-S 耦合：涉及多电子原子中所有电子的轨道角动量和自旋角动量的相互作用，形成总轨道角动量和总自旋角动量，再耦合成总角动量。它主要用于描述多电子原子的能级结构。
		\end{itemize}
	\end{enumerate}

	\end{question}
	
	\begin{enumerate}
		\item 计算钠双黄线的塞曼分裂
		\begin{itemize}
			\item 钠双黄线（Na D 线）是由钠原子从 $^2P_{\frac{1}{2}, \frac{3}{2}}$ 到 $^2S_{\frac{1}{2}}$ 态的跃迁所产生。它包括两个主要的波长：
			\begin{itemize}
				\item D1 线：589.6 nm（从 $^2P_{\frac{1}{2}}$ 到 $^2S_{\frac{1}{2}}$ 的跃迁）
				\item D2 线：589.0 nm（从 $^2P_{\frac{3}{2}}$ 到 $^2S_{\frac{1}{2}}$ 的跃迁）
			\end{itemize}
			
			\item 基础公式
			塞曼效应下能级分裂的频率差（或波数差）与外磁场和朗德因子的关系如下：
			\[
			\Delta \nu = \frac{e B}{4 \pi m_e c} (g_2 m_{J2} - g_1 m_{J1})
			\]
			
			其中，$e$ 为电子电荷，$B$ 为外磁场强度，$m_e$ 为电子质量，$c$ 为光速，$g_1$ 和 $g_2$ 分别为初态和末态的朗德因子以及$m_{J1}$ 和 $m_{J2}$ 为对应态的磁量子数。
			
			\item 朗德因子的计算
			\begin{itemize}
				\item 对于钠原子，朗德因子为：
				\begin{itemize}
					\item $^2S_{\frac{1}{2}}$ 态的朗德因子 $g_S = 2$
					\item $^2P_{\frac{1}{2}}$ 态的朗德因子 $g_{P_{\frac{1}{2}}} = \frac{2}{3}$
					\item $^2P_{\frac{3}{2}}$ 态的朗德因子 $g_{P_{\frac{3}{2}}} = \frac{4}{3}$
				\end{itemize}
			\end{itemize}
		\end{itemize}
		
		\item 计算 D1 线的分裂
		
		D1 线对应 $^2P_{\frac{1}{2}}$ 到 $^2S_{\frac{1}{2}}$ 的跃迁。
		
		对于 $^2P_{\frac{1}{2}}$ 态，$J = \frac{1}{2}$，$m_J = \pm \frac{1}{2}$，$g_J = \frac{2}{3}$
		
		对于 $^2S_{\frac{1}{2}}$ 态，$J = \frac{1}{2}$，$m_J = \pm \frac{1}{2}$，$g_J = 2$
		
		分裂的频率差为：
		\[
		\Delta \nu = \frac{e B}{4 \pi m_e c} \left( g_{P_{\frac{1}{2}}} m_{J_{P_{\frac{1}{2}}}} - g_{S_{\frac{1}{2}}} m_{J_{S_{\frac{1}{2}}}} \right)
		\]
		
		由于 $$m_{J_{P_{\frac{1}{2}}}} = \pm \frac{1}{2}$$ 和 $m_{J_{S_{\frac{1}{2}}}} = \pm \frac{1}{2}$：
		\[
		\Delta \nu = \frac{e B}{4 \pi m_e c} \left( \frac{2}{3} \cdot \pm \frac{1}{2} - 2 \cdot \pm \frac{1}{2} \right) = \frac{e B}{4 \pi m_e c} \cdot \frac{1}{6}
		\]
		
		\item 计算 D2 线的分裂
		
		D2 线对应 $^2P_{\frac{3}{2}}$ 到 $^2S_{\frac{1}{2}}$ 的跃迁。
		
		对于 $^2P_{\frac{3}{2}}$ 态，$J = \frac{3}{2}$，$m_J = \pm \frac{3}{2}, \pm \frac{1}{2}$，$g_J = \frac{4}{3}$
		
		对于 $^2S_{\frac{1}{2}}$ 态，$J = \frac{1}{2}$，$m_J = \pm \frac{1}{2}$，$g_J = 2$
		
		分裂的频率差为：
		\[
		\Delta \nu = \frac{e B}{4 \pi m_e c} \left( g_{P_{\frac{3}{2}}} m_{J_{P_{\frac{3}{2}}}} - g_{S_{\frac{1}{2}}} m_{J_{S_{\frac{1}{2}}}} \right)
		\]
		
		由于 $m_{J_{P_{\frac{3}{2}}}} = \pm \frac{3}{2}, \pm \frac{1}{2}$ 和 $m_{J_{S_{\frac{1}{2}}}} = \pm \frac{1}{2}$：
		\[
		\Delta \nu = \frac{e B}{4 \pi m_e c} \left( \frac{4}{3} \cdot \pm \frac{3}{2} - 2 \cdot \pm \frac{1}{2} \right) = \frac{e B}{4 \pi m_e c} \left( \frac{2}{3} \cdot \pm 3 - \pm 1 \right) = \frac{e B}{4 \pi m_e c} \left( 2 - \pm 1 \right)
		\]
		
		\item 实验步骤设计
		\begin{itemize}
			\item 准备仪器
			\begin{itemize}
				\item 一台高分辨率的法布里-珀罗干涉仪（F-P 标准具）。

			\item 调整实验装置
			\begin{itemize}
				\item 将钠灯点燃，并将其光通过光学透镜和偏振片聚焦到 F-P 标准具上。
				\item 调整偏振片至所需角度以观察不同偏振方向的光。
			\end{itemize}
			
			\item 施加磁场
			\begin{itemize}

			\end{itemize}
		\end{itemize}
		
	\end{enumerate}

	\subsection{实验数据分析（Analysis）}
	
	%
	\subsubsection{分析塞曼效应测量结果}
	\begin{itemize}
		\item 首先在磁场垂直方向上观察，可以看到三种偏振光：$\sigma^+$左旋偏振光、$\sigma^-$右旋偏振光和$\pi$偏振光。$\sigma^+$和$\sigma^-$偏振光的投影与磁场方向$B$垂直，而$\pi$偏振光与磁场$B$平行。
		
		\begin{enumerate}
			\item 当电流为3.3A，偏振片旋转至90\degree 时，谱线分裂为三条，其中只有一个线偏振光透过偏振片。结合偏振片置于0\degree 时的图像分析，可以确定该线偏振光为$\pi$偏振光。
			\item 当电流为3.3A，偏振片旋转至0\degree 时，谱线明显分裂为两个圆环，每个圆环进一步分裂为较模糊的三条谱线，总共分裂为六条谱线。此时透过0\degree 偏振片的是$\sigma^+$左旋偏振光和$\sigma^-$右旋偏振光的投影。
			\item 当电流为3.3A，偏振片旋转至45\degree 时，三个线偏振光都能通过，理论上谱线应分裂为九条。但由于仪器存在误差（误差分析见实验误差定性分析），导致其中两条谱线重叠，实际观察到六条谱线。
		\end{enumerate}
		
		\item 然后在磁场平行方向上观察，可以看到两种圆偏振光：$\sigma^+$左旋偏振光和$\sigma^-$右旋偏振光。
		
		\begin{enumerate}
			\item 根据实验原理和戴鹏辉（22344016）小组的实验图像分析，在磁场的影响下，应该能观察到六条谱线。我们的实验图像在偏振片旋转至90\degree 时的确观察到六条谱线（如图7所示）。
			\item 当电流为3.3A时，虽然理论上此时应为圆偏振光，不会随偏振片的旋转而变化，但实际上确实观察到变化。变化并不是圆环半径的变化，而是由于分裂导致的六条谱线更加清晰。
			\item 谱线分裂为两条粗环，分别代表$\sigma^+$左旋偏振光和$\sigma^-$右旋偏振光。
		\end{enumerate}
		
		\item 结论
		
		在垂直磁场方向上，可以观察到$\sigma^+$左旋偏振光、$\sigma^-$右旋偏振光和$\pi$偏振光。$\sigma^+$和$\sigma^-$偏振光的投影与磁场方向垂直，而$\pi$偏振光与磁场方向平行。
		
		在平行磁场方向上，可以观察到两种圆偏振光：$\sigma^+$左旋偏振光和$\sigma^-$右旋偏振光。
		
		随着偏振片角度的不同，光谱线分裂的情况也不同。在偏振片为90\degree 时，观察到三条光谱线，其中只有$\pi$偏振光透过。在偏振片为0\degree 时，光谱线分裂为两个圆环，每个圆环进一步分裂为三条，总共六条光谱线，表示$\sigma^+$和$\sigma^-$偏振光的投影。在偏振片为45\degree 时，理论上应观察到九条光谱线，但因仪器误差实际观察到六条。
		
		实验结果与理论预测大体一致，在磁场影响下确实观察到了分裂的光谱线。尽管理论上在某些条件下不应出现变化，实际观测中仍出现了一些变化，这些变化主要体现在光谱线的清晰度而非分裂数量上。
		
		这些结论表明，偏振光在磁场中的行为和光谱线的分裂现象可以通过实验观察和理论分析进行验证，并且实验结果与理论预期高度一致，但需要考虑仪器误差对结果的影响。
	\end{itemize}

	\subsubsection{计算荷质比与误差评定}
	\begin{enumerate}
		\item 利用实验测量得到的数据（\cref{tab:tab1}），我们可以进一步进行不确定度评定：
		
		误差传递公式用于计算间接测量量的标准差。对于测量电荷质量比($e/m$)，其误差传递公式如下：
		
		\[
		\sigma_{\frac{e}{m}} = \sqrt{\left(\frac{\partial\left(\frac{e}{m}\right)}{\partial D_{K1}} \cdot \sigma_{D_{K1}}\right)^2 + \left(\frac{\partial\left(\frac{e}{m}\right)}{\partial D_K} \cdot \sigma_{D_K}\right)^2 + \left(\frac{\partial\left(\frac{e}{m}\right)}{\partial D_{K-1}} \cdot \sigma_{D_{K-1}}\right)^2}
		\]
		
		其中，各个偏导数和对应的数值为：
		
		\[
		\frac{\partial\left(\frac{e}{m}\right)}{\partial D_k} = 3.59034 \times 10^{12}
		\]
		
		\[
		\frac{\partial\left(\frac{e}{m}\right)}{\partial D_{k1}} = 2.68123 \times 10^{11}
		\]
		
		\[
		\frac{\partial\left(\frac{e}{m}\right)}{\partial D_{K-1}} = -4.86465 \times 10^{11}
		\]
		
		代入各个偏差值进行计算，得出$e/m$的标准差：
		
		\[
		\begin{aligned}
			\sigma_{e/m} &= \sqrt{(3.59034 \times 10^{12} \times 0.180774)^2 + (2.68123 \times 10^{11} \times 0.372638)^2 + (-4.86465 \times 10^{11} \times 0.473123)^2} \\
			&= \sqrt{(29235304771 \times 0.180774)^2 + (2766906464 \times 0.372638)^2 + (-3730944971 \times 0.473123)^2} \\
			&= 5666570886 \\
			&\approx 5.67 \times 10^9
		\end{aligned}
		\]
		
		扩展不确定度$U$是标准差的$k$倍，置信概率取95\%时，$k = 1.96$，因此：
		
		\[
		U = k \sigma_{e/m} = 1.96 \times 5.67 \times 10^9 = 1.11 \times 10^{10}
		\]
		
		最终的测量结果为：
		
		\[
		\frac{e}{m} = (1.92 \pm 0.11) \times 10^{11} \, \text{C} \cdot \text{kg}^{-1}
		\]
		
		\item 基于不确定度的误差评定与结果评价
		
		根据计算，我们得到电荷质量比($e/m$)的测量结果为：
		
		\[
		\frac{e}{m} = (1.92 \pm 0.11) \times 10^{11} \, \text{C} \cdot \text{kg}^{-1}
		\]
		
		这一结果意味着我们对测量值的置信区间为$1.92 \times 10^{11} \, \text{C} \cdot \text{kg}^{-1}$上下各$1.11 \times 10^{10}$，即在区间$(1.81 \times 10^{11}, 2.03 \times 10^{11}) \, \text{C} \cdot \text{kg}^{-1}$内。
		
		电子的真实电荷质量比值为：
		
		\[
		\frac{e}{m}_{\text{真实}} \approx 1.758 \times 10^{11} \, \text{C} \cdot \text{kg}^{-1}
		\]
		
		将测量结果与真实值进行对比，
		测量值为$(1.92 \pm 0.11) \times 10^{11} \, \text{C} \cdot \text{kg}^{-1}$；
		真实值为$1.758 \times 10^{11} \, \text{C} \cdot \text{kg}^{-1}$。
		
		从数值上看，测量值与真实值存在一定的偏差。然而，真实值$1.758 \times 10^{11} \, \text{C} \cdot \text{kg}^{-1}$落在测量结果的置信区间$(1.81 \times 10^{11}, 2.03 \times 10^{11}) \, \text{C} \cdot \text{kg}^{-1}$内，这意味着我们的测量结果在统计意义上是合理的。虽然测量值与真实值之间有一定偏差，但由于真实值落在测量结果的95\%置信区间内，可以认为测量结果具有较高的可信度和准确性。测量中的误差可能来源于实验设备的精度限制、环境因素和人为操作误差等。这些误差通过不确定度的计算得以量化，从而表明在考虑这些不确定因素的情况下，测量结果与真实值一致。
		
		总的来说，本次测量结果是可靠的，并且在误差范围内与已知的电荷质量比值相符。这表明我们的实验方法和数据处理是有效的。
	\end{enumerate}

	\subsubsection{基于Hough变换与神经网络技术的塞曼效应图像识别创新设想与初步实施}
	以下是关于初步实现这个方法的核心代码部分（Python），然而由于我们实验成像结果太差，这个方法并没有起到一个非常好的效果。因此，这里只简单列举我们的思路。
	\begin{enumerate}
		\item 预处理图像：将图像转换为灰度图像并进行边缘检测。
		\item 使用Hough变换检测圆：使用Hough圆变换检测图像中的圆形谱线。
		\item 使用神经网络分类谱线：训练一个简单的神经网络来识别和分类这些谱线。
		\item 计算荷质比：根据检测到的谱线分裂情况计算荷质比。
	\end{enumerate}
	
	\begin{lstlisting}[style=pythonstyle,caption=方法实现核心代码]
		import cv2
		import numpy as np
		import matplotlib.pyplot as plt
		from keras.models import Sequential
		from keras.layers import Dense, Flatten
		from keras.utils import to_categorical
		from sklearn.model_selection import train_test_split
		
		# 预处理图像
		image_path = '/mnt/data/90°.png'
		image = cv2.imread(image_path, cv2.IMREAD_GRAYSCALE)
		edges = cv2.Canny(image, 50, 150)
		
		# 使用Hough变换检测圆
		circles = cv2.HoughCircles(edges, cv2.HOUGH_GRADIENT, dp=1.2, minDist=30, param1=50, param2=30, minRadius=5, maxRadius=50)
		
		if circles is not None:
		circles = np.round(circles[0, :]).astype("int")
		output = cv2.cvtColor(image, cv2.COLOR_GRAY2BGR)
		for (x, y, r) in circles:
		cv2.circle(output, (x, y), r, (0, 255, 0), 4)
		plt.imshow(output)
		plt.title("Detected Circles")
		plt.show()
		else:
		print("No circles were found")
		
		# 使用神经网络分类谱线
		def create_dataset(circles, image):
		data = []
		labels = []
		for (x, y, r) in circles:
		# Extract the circle region
		circle_img = image[y-r:y+r, x-r:x+r]
		if circle_img.size > 0:
		resized_img = cv2.resize(circle_img, (28, 28))
		data.append(resized_img)
		labels.append(1)  # Example label, adjust as necessary
		return np.array(data), np.array(labels)
		
		if circles is not None:
		data, labels = create_dataset(circles, image)
		data = data.reshape(data.shape[0], 28, 28, 1).astype('float32') / 255
		labels = to_categorical(labels, 2)
		
		model = Sequential([
		Flatten(input_shape=(28, 28, 1)),
		Dense(128, activation='relu'),
		Dense(64, activation='relu'),
		Dense(2, activation='softmax')
		])
		
		model.compile(optimizer='adam', loss='categorical_crossentropy', metrics=['accuracy'])
		
		x_train, x_test, y_train, y_test = train_test_split(data, labels, test_size=0.2, random_state=42)
		model.fit(x_train, y_train, epochs=10, validation_data=(x_test, y_test))
		
		# 计算荷质比
		predictions = model.predict(data)
		for i, prediction in enumerate(predictions):
		if np.argmax(prediction) == 1:
		print(f"Detected split line at circle {i} with radius {circles[i][2]}")
		
		else:
		print("No circles were found, skipping neural network training and charge-to-mass ratio calculation")
